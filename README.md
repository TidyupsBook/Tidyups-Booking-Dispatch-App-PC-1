# HVAC Dispatcher AI

## Overview
HVAC Dispatcher AI is an intelligent field service dispatch and fleet optimization platform designed for heating, ventilation, and air conditioning operations across metropolitan service territories. The application streamlines multi-vehicle fleet routing, real-time technician tracking, and service ticket triage by pairing Google AI Studio's Gemini models for automated schedule recommendations with Google Maps Platform for dynamic route calculation, traffic-aware dispatching, and interactive territory visualization.

## Google Maps Platform Products & Features
- Maps JavaScript API
- Advanced Markers
- Info Windows
- Polylines
- Routes API
- Geocoding API
- Google Maps URLs
- Marker Clustering
